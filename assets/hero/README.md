# L&A Royal Advisory — Hero oceânico 4K

Os arquivos WebP precisam estar neste diretório do repositório para que a fotografia seja exibida. O CSS da branch `feat/royal-ocean-palette-20261118` já aponta para os nomes abaixo.

| Arquivo | Tela |
|---|---|
| `hero-ocean-4k.webp` | TV e monitores de alta resolução (3840 × 2160) |
| `hero-ocean-desktop.webp` | desktop (1920 × 1080) |
| `hero-ocean-tablet.webp` | tablet/notebook (1366 × 768) |
| `hero-ocean-mobile.webp` | celular (960 × 540) |

A pasta original pronta para download foi disponibilizada na conversa em `LA_Royal_Advisory_Hero_Banner_Ocean_4K.zip`.

**Instalação**: enviar as imagens da pasta `assets/hero/` do ZIP para este diretório mantendo exatamente os nomes. Os arquivos não devem ser movidos para a raiz do repositório.

**Fallback**: o CSS deixa `assets/royal-diamond-hero.svg` como camada secundária, garantindo um banner mesmo antes do envio das fotos.

**Responsividade**: o título e o botão são elementos HTML independentes. O background usa `cover` e recortes próprios por dispositivo, portanto as bordas da fotografia podem ser cortadas sem esticar a imagem.

Não inserir informações, botões, preços ou texto dentro da fotografia.
